Vendored character-width data staged in the mosh Windows bundle.

Provenance: this data is NOT original to mosh. It is derived from the
GNU C Library (glibc) 2.39 locale artifact through this chain:

  Unicode Character Database files
    (EastAsianWidth.txt, PropList.txt, UnicodeData.txt, Unicode 15.1.0)
  -> glibc's localedata/unicode-gen/utf8_gen.py
  -> localedata/charmaps/UTF-8
       (sha256 80ca20f5ba81376a4d30c719fc5f56717bc4d613a3442b15ecbfc527a0cdde0b,
        glibc 2.39)
  -> win32/wcwidth_data_glibc_2_39.h
